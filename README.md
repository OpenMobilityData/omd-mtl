# omd-mtl

The short address `omd-mtl.ca` for the [OpenMobilityData site](https://openmobilitydata.ca/).

GitHub Pages serves one custom domain per site, so this repository holds the short name and nothing else: `index.html` and `404.html` are the same page, which sends the browser to the same path on `openmobilitydata.ca`. The site itself, its catalogue and its build script are in [openmobilitydata.github.io](https://github.com/OpenMobilityData/openmobilitydata.github.io).
